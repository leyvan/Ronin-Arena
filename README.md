## Ronin-Arena

# Summary
- Hack-And-Slash, Third Person, Survival game where the point is to survive waves of enemies and complete objectives. You are a contender in an arena where you must fight lots of enemies to prove your worth. The game raises in difficulty by increasing the number of enemies or by adding enemies that take more hits to eliminate or deal more damage to the player.

# Tools/Assets
- Game was developed in Unreal Engine, mostly using the blueprint system with some C++ implementation. I used Non-Copyrighted(NC) assets provided by the Unreal Engine for the character and the enviroment. Aswell as some NC Music and Art for the main menu. 

# Controls
- Using a mouse and keyboard, the player can control the game character movement to move in all directions, jump with SPACE and dash with SHIFT. The attack button will be left mouse click, and abilities will be either the Q or W key, or both.
